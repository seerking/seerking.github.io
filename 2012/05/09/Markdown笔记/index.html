特殊字符原样输出

如果想打出 Markdown 语法已经占用的字符，比如 *，#，| 等该怎么办？简单，在这些字符前加 上反斜线 \ 就好了，如 *，#，| 等。

如何分行

通常当你输入一段文字时，Markdown 并不会按回车符 (Enter) 进行分行。如果你希望换行，你可以在行尾加上两个以上的空格，然后按 Enter 键。如果你希望强制换行，可以在行尾加上两个以上的反斜线，然后按 Enter 键。

生成目录

自动生成目录非常简单，只需要在恰当的位置添加 [TOC] 符号，凡是以#定义的标题都会被编排到目录中。
