Markdown All in One 作者主页

Markdown All in One 是一款功能强大的 Markdown 编辑器插件，专为 Visual Studio Code（VSCode）设计，旨在提升 Markdown 文档的编写和编辑效率。这款插件集成了多种实用功能和快捷键，适用于技术文档、博客文章、笔记等多种场景。

核心功能
  • 快捷键支持：Markdown All in One 提供了丰富的快捷键操作，如加粗、斜体、删除线、插入链接、插入图片、插入表格等，方便用户快速编辑文档。
  • 自动补全：插件支持自动补全功能，包括 Markdown 语法、代码块、标题等，提高编写效率。
  • 代码块语法高亮：插件支持多种编程语言的代码块语法高亮，方便用户查看和编辑代码。
  • 实时预览：插件支持实时预览 Markdown 文档，方便用户查看文档效果。
  • 目录生成与更新：用户可以通过快捷键（如 Ctrl + Shift + P）快速创建或更新文档目录，方便导航和组织内容。
  • 数学公式支持：插件支持 LaTeX 数学公式的插入和渲染，方便用户在 Markdown 文档中插入复杂的数学公式。
  • 自定义快捷键：用户可以根据自己的习惯自定义快捷键，方便快速执行常用操作。
  • 支持多种 Markdown 解析器：插件支持多种 Markdown 解析器，如 CommonMark、GitHub Flavored Markdown 等，用户可以根据需求选择合适的解析器。
  • 支持多种主题：插件支持多种主题，包括默认主题和第三方主题，用户可以根据自己的喜好选择合适的主题。
  • 支持多种扩展插件：插件支持多种扩展插件，如 MarkdownLint、MarkdownTOC 等，用户可以根据需求安装和使用这些扩展插件。
  • 支持多种文件格式：插件支持多种文件格式，如 Markdown、HTML、PDF 等，用户可以根据需求导出文档。
  • 支持多种语言：插件支持多种语言，包括中文、英文等，用户可以根据自己的语言习惯选择合适的语言。

常用快捷键

功能 快捷键 说明
加粗 Ctrl + B 将选中的文本加粗
斜体 Ctrl + I 将选中的文本变为斜体
删除线 Alt + S 将选中的文本添加删除线
插入链接 Ctrl + V 插入一个链接
插入表格 Ctrl + T 插入一个表格
插入代码块 Ctrl + Shift + K 插入一个代码块
切换标题 Ctrl + Shift + [ 切换当前行的标题级别
